致理．心夥伴－活動報名系統 V11.21.0 正式整合版
更新時間：2026/09/12 18:33（台灣時間）

一、檔案內容
1. Code.gs：Google Apps Script 後端完整檔案
2. index.html：GitHub Pages 前端主頁
3. app.js：GitHub Pages 前端程式
4. app-custom.css：GitHub Pages 前端樣式

二、建議更新順序
1. 先將 Code.gs 全部取代 GAS 專案現有的 Code.gs，儲存後部署「新版本」。
2. 確認 GAS 網頁應用程式網址仍與 app.js 最上方 GAS_API_URL 一致。
3. 再將 index.html、app.js、app-custom.css 上傳 GitHub，覆蓋同名檔案。
4. GitHub Pages 完成部署後，以無痕視窗開啟，確認導覽列顯示 V11.21.0。

三、本版主要修正
- 報名專區改為接近活動月曆的寬版內容區。
- 正式加入「列表檢視／圖片檢視」，預設為列表檢視。
- 列表活動標題獨立一列，日期、時間及地點移至標題分隔線下方。
- 有圖與無圖活動保留相同圖片空間，TAG 獨立一列。
- 圖片檢視只顯示圖片、活動標題、TAG、名額狀態及置中的「活動資訊」。
- 圖片左上角為獨立報名勾選框；切換圖片、查看資訊不會誤勾報名。
- 單場、多場、一對一、系列活動均顯示相應名額狀態；額滿活動停用勾選。
- 初始畫面顯示「活動資料讀取中」；確實讀取成功但沒有活動時才顯示「目前無任何活動」。
- 資料暫時未完成載入時改用一般使用者可理解的提示，不顯示 Failed to fetch。
- 活動詳情只在確實有承辦老師資料時顯示承辦欄位。
- 學生報名與老師後台手動新增均檢查既有報名、本次多活動及各場次衝堂。
- 多場次及一對一活動必須明確選擇一場；LINE 行前通知依每位學生實際場次帶入。
- 公開／取消公開寫入後立即更新公開資料快取，降低前後台狀態不一致。
- 加入 Google 行事曆時明確指定 Asia/Taipei，活動名稱維持原標題，不加入前一天提醒。
- 報名表單加入「活動僅限本校學生參加；如無法順利報名，請與個管老師聯繫」。

四、上線後必要測試
1. 登出狀態：未公開活動不得出現在報名專區與活動月曆。
2. 登入後切回報名專區：未公開活動仍不得出現。
3. 公開一場未公開活動後重新整理學生端，活動應出現；取消公開後應消失。
4. 切換列表／圖片檢視，勾選狀態應一致；點圖片箭頭及活動資訊不得改變勾選。
5. 測試單場、多場、一對一、系列活動與額滿狀態。
6. 用同一學生測試重疊場次：學生自行報名及老師手動新增都必須阻擋。
7. 報名成功與查詢紀錄的「加入行事曆」應顯示正確台北日期時間。
